# Features Index

Reference sheets for building specific SVG features. Read only the sheets relevant to your image.

## Character/Face Features

| File | Use When | Content |
|------|----------|---------|
| `features-eyes.md` | Image has eyes (characters, faces) | Eye construction, highlights, gaze direction |
| `features-mouth.md` | Image has mouth (characters, faces) | Mouth shapes, expression, teeth |
| `features-nose.md` | Image has nose (characters, faces) | Nose variations across styles |
| `features-ears.md` | Image has ears (characters, animals) | Ear shapes, head interaction |
| `features-face-shape.md` | Image has face (characters) | Face contour, foundation layer |
| `features-hair.md` | Image has hair (characters) | Hair construction, organic shapes |
| `features-body.md` | Image has full body (characters) | Body proportions, limbs, torso |
| `features-accessories.md` | Image has accessories (hats, glasses, jewelry, clothing) | Accessories, tools, decorative elements |

## Subject-Specific Features

| File | Use When | Content |
|------|----------|---------|
| `features-objects.md` | Image has complex objects (tools, props, held items) | Structural decomposition, multi-surface objects |
| `features-vehicles.md` | Image has vehicles or machines | Panel assemblies, metallic surfaces, precision geometry |
| `features-food.md` | Image has food or drinks | Glossy surfaces, layered construction, steam effects |
| `features-plants.md` | Image has plants or flowers | Radial symmetry, petal construction, vein clipping |

## Quick Reference

**Character images:** Start with `features-face-shape.md`, then add eyes, mouth, nose, ears, hair, body, accessories as needed.

**Non-character images:** Use `features-objects.md` for general objects, or the specific sheet (vehicles, food, plants) if applicable.

**Hybrid images:** Use the focal subject's sheet as primary; treat secondary elements more simply.
